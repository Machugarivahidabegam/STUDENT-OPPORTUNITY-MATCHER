## 📌 Project Overview

**Student Opportunity Matcher – UniPath Career Sync** is an AI-assisted web application designed to help B.Tech students discover relevant career opportunities from a centralized platform.

Students often miss valuable opportunities because internships, jobs, hackathons, scholarships, workshops, and competitions are distributed across different websites and platforms.

This project provides a centralized dashboard where students can find opportunities based on their:

* 🎓 Academic branch
* 💻 Technical skills
* 📍 Preferred location
* ❤️ Interests
* 🎯 Career goals
* 📅 Application deadlines

---

## ❗ Problem Statement

Students miss internships, hackathons, scholarships, jobs, workshops, and competitions because career opportunities are scattered across multiple websites and platforms.

Students need to manually search several platforms to find opportunities that match their skills and interests.

Therefore, there is a need for a centralized web application that can help students discover and identify relevant opportunities based on their profile.

---

## 💡 Proposed Solution

**UniPath Career Sync** provides a single platform for students to discover different career opportunities.

The application allows students to create a profile and enter their branch, skills, interests, preferred location, and career goals.

The system then helps students identify suitable opportunities through search, filtering, categorization, and personalized matching.

---

## 🎯 Objectives

The main objectives of this project are:

1. To create a centralized platform for student opportunities.
